# Student Management API

A simple Express-based API for managing student records.

## Run

```bash
cd studentmanagementapi
npm install
node app.js
```

The API runs on `http://localhost:3000` by default.

## Endpoints

- `GET /health`
- `GET /students`
- `GET /students/:id`
- `POST /students`
- `PUT /students/:id`
- `DELETE /students/:id`
